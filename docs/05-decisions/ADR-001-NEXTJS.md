# ADR-001 — Next.js

## Status

Accepted

## Decision

Use Next.js as the application framework for GeoWeb Solutions V2.

## Context

The application requires:
- public pages
- server-rendered functionality
- API routes
- protected administration
- static generation for content pages

Next.js provides these capabilities within one application.

## Consequence

The project follows the Next.js App Router and its server/client component model.
