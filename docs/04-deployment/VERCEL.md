# Vercel

## Project

`geoweb-solutions-v2`

## Framework

Next.js.

## Node.js

Vercel project runtime: Node.js `24.x`.

## Build

The project uses:

```bash
pnpm run build
```

which executes Prisma generation followed by:

```bash
next build
```

## CLI

The Vercel CLI was used through:

```bash
npx vercel
```

The CLI was not installed globally in the local environment.
